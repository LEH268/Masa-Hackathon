# 🚀 MASA Hackathon Project

This project is developed for the **MASA Hackathon** using **Streamlit** to build an interactive and user-friendly web application.

🌐 **Live App**: https://masa-hackathon-teqcdydexuqmhvsskstpuw.streamlit.app/

## 📌 Overview

This application is built using **Python and Streamlit**, allowing users to interact with a web-based interface easily. It focuses on rapid development, simplicity, and usability, making it suitable for hackathon deployment.

---

## ✨ Features

- ⚡ Fast and interactive UI using Streamlit  
- 📊 Clean and simple user interface  
- 🤖 Built for rapid prototyping and hackathon submission  
- 🌍 Fully deployed on Streamlit Cloud  
- 🧠 Python-based backend logic
